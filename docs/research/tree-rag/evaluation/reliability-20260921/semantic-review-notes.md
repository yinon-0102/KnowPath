原文（第7页第二十一条）将“未满八周岁**或者**由于身体、心理原因需要特别照顾的未成年人”
列入不得处于无人看护状态的范围。

1. B1最终保留结论写“但该限制**不适用于**虽年满八周岁但因身体、心理原因需要特别照顾的未成年人”。
   这存在把并列保护范围反向解释成豁免的明确风险。A对应表述为“该限制**亦适用于**”，方向不同。
   B1第二轮checker仍标supported、conditions/exceptions preserved、negation not_applicable。
   工程引用校验通过不能证明模型识别了这个否定/例外错误。
2. 两条最终答案都丢失了题目明确涉及的十六岁条件。草稿结论含“第二十一条”和“十六周岁”，
   所选跨度 `[110,149)`含十六周岁，却不含条号21（条号位于 `[0,26)`），
   数值规则因此给出NUMERIC_FACT_NOT_IN_CITED_SOURCE。这是条号与事实数字混查造成的误拒迹象，
   同时也说明模型没有选择覆盖其全部文本的证据段；不能归为检索没有资料。
3. c1所选跨度 `[0,54)`止于“未成年人处于”，未包含下一段的“无人看护状态”，
   checker却确认支持。这说明使用本地有效段ID只能保证坐标真实，不能保证所选段的语义证据充分。
4. 两条都未明确义务主体；是否需要复述主体，应结合问题语境审查。
   草稿金标还包含“不适宜人员临时照护”，但问题只问两种状态的年龄条件，是否属于必答项需要人工定夺，
   不能因自动草稿列出了该项就自动判错。
