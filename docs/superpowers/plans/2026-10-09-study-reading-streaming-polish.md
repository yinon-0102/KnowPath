# 学习路线、原文阅读与流式输出修复计划

目标：按用户要求在现有双模式学习区修复路线重复布局、Markdown 原文显示及模型流式呈现；保留配色、节点身份、真实数据和独立测评规则。

实施采用 writing-plans 与 subagent-driven-development 工作流。工作区已有未提交功能，直接在当前工作区增量修改，不重置、不提交，不启动常驻服务。

## 设计选择

保持顶部节点路线，降低高度并明确当前节点、完成比例。学习计划页改为清楚的任务列表，移除重复路线；历史轮次独立折叠且不重复当前路线。与改为固定侧栏或重新绘制大图相比，这种改法保留用户已确认的顶部路线，移动端也能使用。

Markdown 原文默认排版阅读，保留源码切换；纯文本和 PDF 保持对应格式。复用安全 Markdown 渲染，补有序列表、引用、表格和代码块，原 HTML 不执行。

回答消费已有 SSE 增量，生成中显示暂存正文，最终校验成功再显示正式结果与来源。讲义通过现有模型 worker 使用流式 provider，每个结构和引用已经校验的小节作为增量事件交付，不显示裸 JSON。来源审计、取消、失败、重试与迟到响应防护同时覆盖增量内容。
