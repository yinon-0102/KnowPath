# 学习阅读侧栏问答与节点样式调整

用户批准实施，2026-10-10。实施期间不重启项目服务，不新增常驻服务或数据库迁移。

## 页面与上下文

- 桌面 ≥1100px：阅读区旁默认展开约 340px 问答侧栏，可收起；窄屏由“提问”打开右侧抽屉。
- 原文无需生成讲义即可提问。候选覆盖当前文档完整可用内容，仍限制空间选中主题、排除主题和绑定版本。
- 讲义问答使用当前有效讲义及其原文；生成未完成或失效时禁用，提供切回原文入口。
- 按空间、节点、原文资料版本或讲义版本保存独立对话、输入和任务引用；不用活动学习会话 ID 共用聊天。
- 消息 POST 增加可选 reading_context（material_id、material_version_id），与 lesson_id 互斥；历史增加对应引用字段。上下文保存在消息快照，旧调用兼容。

## 状态、阅读与视觉

- 保留 SSE 增量正文、最终引用、停止、失败和同 Run 恢复。切换只断开旧订阅，保存 Run；迟到响应不得覆盖新上下文。
- 阅读正文与重放继续执行辅助作答审计。失效来源清除暂存正文、输入和依赖会话，提示更新依据。
- 流式更新保留 PDF iframe 浏览上下文、Markdown 与讲义阅读位置、侧栏滚动及输入；不强制滚到底部。
- 底部追问移入侧栏；会话、测评、笔记仍在阅读区底部。
- 选中节点白底、蓝色标题、短下划线；正在学习使用单层细边圆点；完成节点保持实心颜色与勾号。保留状态文字、键盘焦点和选中语义。
- 不增加划词提问、批注。

## 实施及验证

顺序：后端上下文与隔离 → 前端多上下文状态 → 侧栏 → 节点样式 → 集成验收。

验证原文无讲义问答、跨资料/版本隔离、切换与迟到响应、断线恢复、取消、失败、删除与辅助审计；验证桌面/窄屏、键盘、阅读位置与输入保留。执行前端 check、完整测试和后端相关回归。
