# 自动学习笔记实施与验收

## 已批准范围

笔记保存在现有 MySQL 中；`review-notes/{空间标识}-{空间ID短码}/`、README 和 Markdown 章节均为虚拟结构，无需本地笔记文件。空间重命名保持目录不变。每个稳定进度节点一个章节，编号为首次出现时的计划轮次与节点序号；继承节点继续追加原章。计划建立时登记空章节和冻结主题，不回放历史测评。

只有关联计划节点的测评完成才登记结构化草稿、独立 Run 与 `note.generate` Outbox。自由测评只保留测评结果。未测评会话只显示待总结。现有 model worker 在事务外调用已配置模型，持久化租约、自动重试、取消和重启恢复保持原机制。

系统确定范围、真实时间、测评结果、来源、状态与证据资格；模型只整理增量正文与纠偏解释。固定正文包含学习范围、核心知识、学习时间、测评结果、理解纠偏、待巩固内容、验收与来源。计时缺失明确显示未记录，现有起止计时包含暂停。模型输出必须引用有效证据，不能扩展到未学习主题或自行判定掌握。

章状态仅 `IN_PROGRESS` / `COMPLETED`，生成状态独立。完成要求规范节点任务完成，冻结主题全部在当前知识版本下达到既有 mastered 规则，不采用单次高分捷径。纠偏以题目稳定身份去重，有效评分与原文依据支持确认，独立复测另行标记；人工编辑不改变资格。辅助作答、简答未验证、撤销和过期证据不充当独立掌握证明。

用户可编辑正文块与纠偏说明、追加个人段落。生成时读取最新章并追加；乐观锁 `expected_version` 阻止覆盖人工编辑，变更保留历史版本。评分复核、隔离、重置、任务完成与采用知识更新后重算状态，不虚构学习内容。

阅读正文、历史版本和草稿经过既有辅助作答审计。索引与历史列表仅暴露摘要。空间归档保留笔记，删除空间级联删除笔记与任务。删除资料清除依赖的生成块、纠偏、草稿及历史副本，保留独立个人段落，取消任务并阻止迟到发布。

## 接口

所有接口沿用 `/api/v1`、本地鉴权和错误契约。

| 接口 | 用途 |
| --- | --- |
| GET /notebooks | 跨空间笔记册摘要 |
| GET /learning-spaces/{space_id}/notebook | README 与章节摘要 |
| GET /note-chapters/{chapter_id} | 正文、依据、草稿与生成状态 |
| PATCH /note-chapters/{chapter_id} | 带 expected_version 编辑块与纠偏 |
| GET /note-chapters/{chapter_id}/revisions | 历史摘要 |
| GET /note-chapters/{chapter_id}/revisions/{revision_id} | 经审计的历史正文 |
| POST /note-generations/{generation_id}/retry | 带 Idempotency-Key 创建重试 Run |

测评结果新增 `notes`、节点学习记录新增 `note` 引用，不删改原字段。

## 前端与运行

沿用原配色和风格，新增顶栏与空间内“学习笔记”、测评完成页与节点详情链接。正文支持代码块、禁用原始 HTML、支持来源跳转。失败展示结构化草稿与重试，409 保留未提交编辑并提供显式合并最新版本。空状态不填示例。

部署前从项目 `py` 目录执行 `.\.venv\Scripts\python.exe -m alembic upgrade head`。新迁移 `0016_learning_notes` 只新增四张持久化表。已有计划首次读取笔记册时回填编号，不生成历史正文。

自动生成复用原 model worker，无新增常驻服务。启动命令：` .\.venv\Scripts\python.exe -m knowpath_backend.learning.workers.model_cli`。配置沿用现有 `.env` 的模型参数与数据库连接。服务由用户手动启动。

## 验收清单

- 存储：内存与 SQL 一致，迁移升级/降级与 ORM 结构一致，重启保持稳定章节编号。
- 触发：两种测评结算路径、重复结算、自由测评、未测评会话与历史计划。
- 内容：真实时间与缺失时间、未验证简答/辅助作答、范围限制、证据引用、模型无效输出。
- 增量：失败草稿与重试、新 Run、后续复测追加、生成期间人工编辑、版本冲突、历史正文。
- 有效性：单次高分不完成、冻结主题全集、当前版本、重置/复核/隔离撤销状态与纠偏资格。
- 生命周期：归档保留、空间删除、资料删除清理历史/草稿、租约取消/重启恢复/迟到输出、跨空间来源审计。
- 前端：导航入口、README、正文/纠偏编辑、历史、重试与轮询、安全 Markdown、来源跳转。
- 回归：笔记专项、迁移、测评/worker/计划/删除/知识更新 pytest；前端 npm.cmd run check 与 npm.cmd test。
