# B4 最终树形实验设计：有界导航与原文证据包

日期：2026-09-24

状态：用户已批准实现。2026-09-24 完成本地实现并进入索引阶段；指标尚未产生，未提交或推送。正式评测固定为一轮 40 题 × A0/F/B4，共 120 条，不重复三轮。执行进度和中断记录以实施计划及隔离评测目录为准。

目标：用一次预先冻结的实验判断“模型利用树选择阅读范围、再读取完整原文”是否比普通 RAG 和同等模型预算的平面检索更值得保留。若未达到门槛，结束在线树检索方向，不追加 B5。

## 1. 先说明什么已经知道，什么尚未证明

当前 B3 的单位检索以原解析 continuation 单元为对象。本项目修复实验使用冻结叶向量的归一化均值作为单位向量；没有真正的章节摘要表示。`UnitFirstPlugin.retrieve` 对无 A 候选种子的单位记录 `no_a_seed` 并跳过，限制了独立结构召回。

最新复核确认：B3 相对旧批次引用覆盖从 72.0833% 到 57.0833%，下降 15pp；旧批次重试贡献 5pp，旧首轮仍为 67.0833%。39/40 个 B3 首轮模型请求体重建一致，全部 8 道引用下降题首轮输入相同。这说明需要修好生成/核验/保留路径，不能只归因于树或随机性。

当前候选 Recall@40 已接近饱和。最终实验不以进一步提高候选 Recall@40 为主要收益目标，而检验“预算内必要原文是否进入上下文，以及能否形成有用引用答案”。这是一次项目取舍，不是对所有树形 RAG 的普遍有效性检验。

## 2. 文献依据与选型

| 候选方向 | 公开方案提供的机制 | 对本项目的判断 |
|---|---|---|
| 完整 RAPTOR 复现 | 递归聚类、摘要树、多层节点检索 | 与现有解析目录及严格原文引用的改动跨度大；最后一版不引入聚类、摘要直接答题等第二套实验 |
| LlamaIndex AutoMergingRetriever | 命中同父节点多个子块后合并父块 | 比只补 continuation 更广，但仍主要依赖已命中叶子；作为上下文完整性参考，不作为此次核心假设 |
| PageIndex 启发的有界导航 | 利用目录层级和节点描述选择阅读路径 | 推荐；直接改变树的作用，让它独立决定去哪里找原文，但严格限制模型调用和展开次数 |

主机制只选第三种。借鉴 RAPTOR 的“高层描述有助于定位不同粒度信息”和 LlamaIndex 的“上下文应保持完整”，不声称是三个框架拼接或论文原方法复现，不引入三个外部框架依赖。

论文依据：RAPTOR 的 controlled comparison 中，QASPER 同用 GPT-4，DPR F1 53.0，RAPTOR 55.7；论文最终采用跨层 collapsed-tree 检索，并非固定由根逐层遍历。本方案第一步因此允许从任意层级的相关节点进入，而不是强制从根选择一条路径。PageIndex 官方描述树索引加模型导航；这些事实支持研究假设，不保证 KnowPath 获益。

## 3. 与既有约束的明确差别

以下设计变更已随方案获得用户批准；具体外发与异常重发仍按执行时确认的范围记录：

| 项目 | B4 提案 |
|---|---|
| 模型、资料、解析叶子 | 仍使用现有模型及三份资料；不换更强回答模型，不重切叶子 |
| 结构关系来源 | 仍只有解析器可确定的章节、父子、原文顺序；模型只能选择关系，不能创建事实关系 |
| 索引表示 | 允许生成章节/语义单元导航卡摘要；摘要只定位，不进入回答证据或可引用事实 |
| 在线导航 | 新增最多 2 次短模型调用，预算与实际 usage 单独计入；不冒充原来的调用预算 |
| query embedding / rerank | 每请求仍最多 1 次 query embedding、1 次 rerank；向量在各检索范围复用 |
| 最终候选与上下文 | 最多 40 个唯一原文叶子；证据预算 5,000，回答输入/输出 14,000/2,000，沿用现有计数口径 |
| 延迟门槛 | 仍为 B4 P95 ≤ 当批 A0 的 1.2 倍；导航放不进这个限制也判定不值得保留，不事后放宽 |
| A 候选保留 | 从原 A retention@40≥0.98 改为强制保留 A 的前 20 个候选、完整报告保留比例；允许树替换后 20 个名额。这是明确变更，不偷偷放宽旧 B3 门槛 |
| negative labels | 保留全部冻结标签，另列既有结构审计；不因 B4 输赢改标签；改用必要证据不回退门槛，不把“没有结构展开”当作最终目的 |
| 默认与回退 | 实验期间普通 RAG 保持默认；B4 无效/超时回退 A0，耗时、已付出调用和回退原因都保留 |

说明：40 候选与 98% 保留对一个恰有 40 候选的集合，实际上不容许替换任何一个叶子（39/40=97.5%）。最后实验要允许独立结构候选参与，同时以最终证据、质量和成本门槛防止无收益扰动。20/20 是本次固定资源配额，不根据答案调节；系统仍有预算参数，不能宣称“完全无参数”。不引入人工加权总分、阈值扫描或路线分类器。

## 4. 共同前置修复：所有组公平应用

新建 A0 作为共同修复后的普通 RAG。历史 A、B2、B3 只作背景，不能将 A0 的普遍修复收益记到 B4。

### 4.1 数值出处检查

修复将证据编号 `s11` 当作 11、将“二元对举”按金额 2 元检查的误判。编号识别必须绑定请求内已知 ID；不能笼统删除所有字母数字串，以免抹掉公式、维度、产品型号等有效信息。

区分概念表达与事实数量，保留对真实年龄、金额、次数、维数、比例的约束；若不能可靠确定属于数值事实，不得仅凭字面数字差异直接覆盖语义核验。用通用正反例测试，不用 40 题题号或答案白名单。例如“二元对举/二元运算”与“金额二元/罚款二元”必须区别处理；证据编号 s11 与事实数字 11 也必须区别处理。

### 4.2 草稿与核验的引用契约

消除要求模型重复拼写多份同义引用集合的脆弱性。草稿声明保有来源绑定；核验通过 claim_id 和 evidence_id 指向受限原文片段，由本地映射导出引用集合。核验只能支持当前声明已引用来源内的证据，不能静默引入新来源。

对支持证据是草稿引用子集的情况，允许保留经片段检查的子集；若需要新来源，则进入现有一次修订、重新核验路径，不直接放行。去重在边界检查前进行，未知 ID、越权 ID、证据不支持、缺失必要检查仍拒绝。明确这是三个组共用的契约调整，不只让 B4 放宽验证。

限定语、数值、依赖、必要要点检查仍全部执行。第 39 题依赖删除不通过直接去掉 depends_on 修复；生成模板应明确只有真实推理依赖才填写，并沿用安全删除不成立依赖的规则。后续合法语义结果仍优先，不为了覆盖率复活被否定内容。

### 4.3 观察记录

在生成之前持久化候选、重排、上下文选择和来源映射的独立快照。生成失败不会再使检索指标缺失，也不会把“未交付上下文”误当作“检索没有找到”。

本地受控诊断保存去除认证信息后的结构化草稿/核验对象或精确违规元素与请求绑定，记录校验前、校验后的状态，避免只有 `semantic_result` 无法复现。仅实验本地敏感产物，不提交原文答案、凭据或认证头。保留 provider failure、contract invalid、semantic unsupported、numeric rejection、dependency pruning 等独立类别。

共同修复先用现有真实失败轨迹及单元/集成测试验证并冻结；不在正式 120 条过程中继续改变代码、提示词或计分规则。若共同链路无法通过离线验收，先报告“实验前提未成立”，不能把它记为树无效。

## 5. B4 数据与索引

### 5.1 原文为权威，导航卡为派生对象

复用现有 scope、manifest、material_version、tree_version、source_spans、leaf_id。树按文档 → 章节/小节 → 可读原文单元组织。章节不存在时记录 structure_unavailable 并回退，不让模型凭空推断目录。

每张导航卡保存：node_id、父/子 ID、原文标题和范围、ordered_leaf_ids、source_map_hash、原文 hash、导航摘要、摘要模型与提示 hash、摘要生成状态。禁止使用测评题、金标准或答案生成摘要。

摘要从本节点原文生成；超出单次预算时按原文顺序分区后组合，保留所有 child/source 绑定，摘要每个版本只生成一次并缓存。不以继承旧叶向量均值代替摘要 embedding。摘要不得作为事实证明，node_id 不能转换成最终引用。

标题、原文、摘要都属于不可信内容，不得改变工具选择规则、权限或输出契约。摘要含错误可能导致漏选，必须通过逐题 route/candidate/context 轨迹暴露，不能假设“有 source IDs 即摘要真实”。

### 5.2 原文证据包

终端可读单元优先采用解析器确定的完整条文、定义、段落及 continuation 组。可把同一明确小节内的相邻完整单元合成阅读包，但不能把相邻直接解释为支持关系。

按 `(ordinal, leaf_id)` 顺序贪心累积同小节的完整单元，遇章节边界、累计 8 个叶子或 1,600 的现有证据预算计数上限即结束当前包；不使用问题或金标准选择包边界。不可分割单元超限时标记 oversized，从导航包候选中排除并明确记录，普通 A 路径仍可按原有预算处理，不能假称该处有可用的完整导航包。跨章节问题可以选择多个包；不允许一次把整章、整本文档塞进模型。

导航摘要只为分组后的阅读包和真实章节节点生成，不为每个旧叶子重复生成。建库前先计算实际包/章节点及分区归并调用数；若超过摘要调用上限，不发起部分建库后再追加预算。当前 source manifest 含 970 个叶子、934 个 continuation 单元，不能把“每个旧单元一次摘要”误当成≤400 次的方案。

包正文是有序原文，记录叶子边界与真实标题，复用现有权威来源映射，最终仍引用原文叶子/片段。不是模型摘要，也不是新增不可追踪父节点证据。

### 5.3 建库成本与隔离

新卡片/摘要向量置于独立版本化索引，绑定原叶索引；不重建生产库，不改变 `.env`。发布前检查源 hash、完整映射、无越权叶子、摘要输出边界和集合 profile。

建树模型预算上限：400 次摘要调用，每次最多 8,000 输入计数单位、512 输出 token；embedding 单独记录。预计调用数、上界、实际 usage、用时及失败卡数落盘。超过预算停止，不丢弃超限章节后冒充全覆盖。价格未冻结时金额保持 unknown，不能称为免费或给出估算报价。

## 6. 在线流程：有界导航、原文阅读、统一回答

1. 获取本次授权来源快照；一次 query embedding 得到 q。复用原混合检索计算 A 的 40 候选，作为固定保底列表，不需要先执行 A 的回答。
2. 用 q 在独立导航卡索引跨层召回，再按现有等权 RRF 合并标题/摘要词法和向量结果，取至多 12 张卡。没有 A 种子的节点也可入选。保留已有 RRF，不新写“语义×0.45＋结构×0.2”等调参公式。
3. 导航调用 1：输入问题、卡片及 B4 的父子路径，返回至多 3 个 node_id，以及每个节点对应的问题子项。只输出短结构化选择，不请求长思维过程，不输出答案、权重或自报置信分。
4. 将选中节点展开为一个阅读前沿：已是原文包则作为包候选，仍为大章节则按真实父子链枚举其后代包，并保留路径。候选前沿至多 24 个包；超过时只用已冻结的 q/词法排序裁剪，记录未展示数量。导航调用 2 阅读这些包的标题、短导航摘要和来源范围，最多选择 3 个包；包的完整原文随后由本地权威源加载。最多两步，不能无限递归、反复重问；从任意层级进入避免固定根路径锁死。无可用后代包的章节点明确跳过。
5. 解析选中包为原文叶子，按导航返回次序接纳完整包，在最多 20 个结构叶子名额内去重。包完整装不下则跳过并记录；不是截取前几叶伪称完整。超过两步仍不能落到原文时回退/忽略该节点并明确 trace。
6. 强制保留 A 排名前 20 的叶子，合入树路由的最多 20 个叶子，重叠不占重复名额。剩余位置按 A 原始顺序补齐，最终≤40。该规则无需浮点融合新旧模型分数。
7. 一次 rerank：B4 用完整包的原文作为排序对象，未被包覆盖的候选保持原有最小语义单元；参与排序的唯一叶子≤40，同一叶子不重复出现在多个包。按 rerank 排序后在 5,000 证据预算内整体装包，不为了某包删除未知需要的其它证据后强称保留率更高。
8. 交给与 A0/F 完全相同的生成、核验及引用映射链。摘要和导航模型的推断都不进入答案依据。保存原文 context hash 以区分检索变化和相同输入下的输出差异。

菜单的 12/24 是对象数量上限，不保证全部塞入 4,000 输入预算。先预留系统协议、问题及输出结构，再按冻结排名接纳完整卡片；只可采用建库时缓存的短卡描述，不在运行时临时再总结或截断原文事实。完整记录呈现/遗漏 ID，F/B4 使用相同的菜单计数和溢出规则，不能以调用数相同冒称输入成本相同。

包去重/不重叠通过固定叶子分区实现，不能把已授权叶子的真实 `requires`、continuation 或 source span 覆写为模型提供的关系。所有被纳入的依赖仍须在候选与上下文闭合；闭合后超出 40 叶预算时跳过新包并记录，不牺牲 A 前 20 的硬保留条件。没有有效包或未能形成合法导航选择时，回退的是完整原 A 候选/排序链，而不是混合了一部分未验证树选择的链。

统一导航预算：同一现有 chat 模型；每次导航输入最多 4,000 计数单位、输出最多 512 token，两次合计至多 20 秒；无导航重试。超时、无效 ID、空路由、结构未就绪时使用 A 保底，已发生的费用、耗时和错误不抹去。认证/全局费用上限按现有停止策略处理。总请求 deadline 仍为 240 秒，模型单调用上限 120 秒；导航消耗总 deadline，不能另加 20 秒。

包排序需要真实扩展现有 rerank plan 并维护叶子映射，不能将摘要或未授权路径直接交给现有 registry 的 Candidate 模型。

## 7. 三组比较与归因边界

| 模式 | 检索/阅读策略 | 在线导航上限 | 共用部分 |
|---|---|---:|---|
| A0 | 共同修复后的普通混合检索 | 0 | 叶子、模型、预算、生成/核验、评分 |
| F | 平面摘要卡片检索及原文筛选，无树遍历、无父包整体阅读 | 2 | 与 B4 相同的摘要卡语料、导航模型、调用/输入输出上限与 20/20 配额 |
| B4 | 跨层入口＋有界父子导航＋原文包整体阅读 | 2 | 同上 |

F 是必要对照：如果只是摘要提供新语义表示或多两次模型选择就能获得相同收益，就没有必要保留在线树导航。

F 的具体路径：首轮面对同一批卡片但移除父子边和路径编码，保留卡自身标题/摘要，选择至多 3 张卡；通过每张卡的原文来源映射获得叶子搜索范围，用原始问题和 q 对叶子做混合排序，第二轮面对至多 24 个平面叶子/已存在 continuation 单元，选择至多 3 个单元。先加入选中单元，再按该叶子排序补充至多 20 个导航来源候选；不因为命中一个叶子展开兄弟或更大父包。与 A 前 20 候选合并、补齐 40 后，执行一次原有叶子/continuation rerank 和相同上下文装配。

F 与 B4 的调用预算上限相同，实际 token 和耗时未必相同，必须报告。F 共享结构派生的摘要卡，所以这个对照检验的是“在线树导航＋包阅读”相对平面摘要检索的价值，不是证明所有结构信息的独立因果效应。二者共用预处理的成本也都必须计入比较，不能声称 F 没有索引开销。

## 8. 120 条冻结测评：先写规则，后看结果

沿用原三份资料和原 40 题，一题每模式一次，总计 **40×3=120 次端到端请求**；A0/F/B4 替换旧 A/B2/B3 组合。本次不新增“更适合树”的题，不修改金标准，不补齐旧批次、不与历史结果混合。已有 40 题属于见过的开发题，不能改称盲测或泛化证明。

这 120 条不等于 120 次 API：F/B4 各 40 条、每条最多两次导航，因此最多额外 160 次在线导航调用；索引摘要和 embedding 单独计数。导航和回答内部一次修订都有明确上限，不能将它们漏记成无重试成本。

模式顺序逐题轮换；所有请求分别真实执行，不跨模式重用答案。模型请求配置、卡片摘要、索引、代码、来源、评分脚本、预算与顺序全部冻结。统一记录 provider 采样设置；未验证的 seed 参数不强行发送，不能承诺输出确定性。

请求级/传输失败照实计入 40 分母，不选择性重试；契约降级空答案计为交付失败，不把 HTTP/流程完成当有效答案。落盘包含每次尝试、进度及时间。监控与运行进程分离，支持有记录的前缀核验与恢复：仅处理未有终局记录的键，已有记录不覆写；崩溃中有已发出但结果未记录的 attempt 标为 unknown，不自动重放或假称未收费。报告中断时序和完成/失败/未知分母。基础设施故障使比较无效时，先报告无有效结论，不自行重跑一批直至好看。

### 8.1 指标

必须包含以下原始指标，不合成加权总分：

- 检索：候选、重排 Recall@1/3/5/10/20/40；原口径 NDCG@10/MRR；必要证据全覆盖题数。
- 独立上下文：生成前必要证据覆盖率、每题全部必要证据是否齐全；与生成后的交付指标分开。
- 交付：最终引用必要证据覆盖率、非空已核验交付数、answered/partial/insufficient/failed、契约错误/恢复次数、完整回答率。
- 树贡献：新增原文金标准证据、路由遗漏、包溢出、A 前 20 保留、叶子数、上下文 hash 改变、相同/不同输入组的引用变化；相同输入的差异不得直接归功于树。
- 成本与可靠性：P50/P95 总时延、纯导航时延、embedding/rerank/chat 调用数、输入/输出 token、索引构建资源、导航失败/回退、provider 失败。
- 质量：模式匿名后按原文审查所有得分变化题和新错误题，检查必要要点、事实支持、引用相关性。模型辅助评审注明自动评分，不能冒充人工；无人复核时正确性=unknown。

冻结统计：40 题配对差异，family 等权、10,000 次 bootstrap、seed 20260924、95% 区间；分别报告 B4−A0、B4−F。单次运行只能作项目工程决策，不能声称估计了同题生成方差或稳定统计提升。

### 8.2 必须同时通过的保留门槛

以下为本次预先约定的工程门槛，不是论文给出的万能阈值。批准后不根据测评结果改变。

| 检查 | 要求 |
|---|---|
| 实际原文进入上下文 | B4 相对 A0、F **分别**提升必要证据覆盖至少 3pp；生成前测量，不利用对照生成失败计零来过关 |
| 最终引用 | B4 相对 A0、F **分别**提升至少 5pp；含失败/空答案分母 |
| 收益不能全来自输出波动 | context hash 改变题组对引用总差的贡献必须为正，且盲审确认至少两道题存在真实上下文/必要证据改善带来的有效回答收益；相同输入组不能成为唯一收益来源 |
| 排序与局部任务 | 统一叶子展开后的 NDCG@10 相对 A0 不下降超过 1pp；原 18 个负标签题上下文覆盖平均下降不超过 1pp，人工不得新增严重事实或出处错误；03/10 的结构审计另列，不改标签 |
| 交付与可靠性 | B4 非空已核验交付数不低于 A0/F 任一组；契约空答案数、请求级失败数不高于任一组；越权或无来源引用为 0 |

| 在线成本代理 | B4 平均输入 token、平均输出 token分别≤A0×1.5；F/B4 导航调用数均在固定上限内。实际金额未冻结则标 unknown，不能称经济门槛已验证 |
| 质量复核 | 得分变化题已按原文完成独立于模式标签的复核，未发现以不可靠内容换取引用覆盖；未复核即不得上线 |

## 10. 退出规则

1. **B4 达不到任一效果/可靠性/时延门槛：** 不保留在线树检索作为主方案，不再设计 B5，不选择性补跑来改变结论。
2. **F 与 B4 相当或更好：** 没有证据支持在线树遍历和包阅读的额外价值。关闭 B4；F 是否单独采用按其相对 A0 的收益和成本报告，不能称为树优化成功。
3. **B4 通过全部工程门槛及质量审查：** 才作为受控可选模式保留；普通 RAG 仍可回退，不能凭 40 道见过的题直接全量替代。
4. **未完成或证据未知：** 不宣布科学上无效，也不放宽门槛；默认仍 A0、不继续扩大树开发，完整报告未知项供用户决定。
5. 无论结果如何保留源解析章节、原文引用映射、共享数值/核验修复和评测归档。退出的是在线树检索算法及派生索引维护，不删除通用文档结构或用户资料。确认退出后才移除运行入口；不直接删除历史分支/数据。
