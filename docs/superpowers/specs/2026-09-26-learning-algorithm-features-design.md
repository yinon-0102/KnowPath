# KnowPath 四项学习算法功能设计

用户已明确要求继续实现此前提出的四项功能：自适应诊断与前置知识排查、掌握度演化与动态复习、时间预算下的计划比较、策略回放与学习效果评估。本轮延续当前分支和上一轮正确性修复；实现及后续模块化本地提交均已获用户授权，不部署、不修改真实凭据或业务数据库。

## 方案和边界

采用可版本化、确定性、可解释的规则策略，并复用现有封存题目、来源、独立证据及事务机制。完整替换为未经本项目数据校准的认知概率模型，会引入无法验证的参数；仅增加报表又不能改变实际选择，因此本轮在真实选题和复习时间上落实策略，同时提供比较及回放。规则分数、证据充分度、预算优先级均不称为经验证的掌握概率或预期学习收益。

四个模块分别独立测试，共享现有证据独立性、题目纠错、reset epoch、知识 revision、范围和时间语义。策略不能自动扩大用户学习范围、复活已撤销证据、把辅助答题视为独立观察，或用未来答案决定过去的推荐。

## 1. 自适应诊断

现有创建测验接口增加可选 adaptive=false，旧流程默认不变。开启后封存当前学习状态、历史题族和选题策略版本，在已验证题池内逐题选择。每次仅接受当前已展示问题的一次独立提交；后续选择在同一答案事务内记录，幂等重放不重复推进。完成后统一进入现有 finalize/evidence 流程。

初题优先薄弱或证据不足主题；遇到客观题错误，优先选择范围内、已确认前置关系对应的可用诊断题。前置缺口只作为假设，独立验证后记录 supported/not_supported/inconclusive，不据此直接修改知识图谱或认定因果。无候选时明确说明缺少题目，不能编造题目或扩大范围。开放题/辅助作答不作为确证缺口或成功掌握的独立依据。

新增 GET /assessments/{assessment_id}/diagnostic，返回当前问题和逐步选择依据、证据标识、假设状态及已完成进度；不泄露未来题目、答案键、评分标准或源正文。生成提示可携带封存选题需求及已用题族，但不声称已完成语义题族去重。

## 2. 掌握度演化与动态复习

保留 mastery-v1 的可解释证据均值与充分度条件，独立引入 review-v2 调度规则。以当前 revision/epoch 下有效、未撤销、未辅助、去重题族的原始观察为输入；正确性、不同测验之间的真实时间间隔和题目难度/应用信息影响复习阶段，错误缩短间隔，重复评分或辅助答题不推迟复习时钟。规则参数、阶段、依据和限制公开。

状态读接口、规划器和新增 GET /learning-spaces/{space_id}/evolution 使用同一调度函数，消除原有 7 天与 1/3/7 天的差异。演化返回原始观察、后续纠错和重置的可追溯事件及当前有效曲线；区分当时观察时间与后来修订时间，不将修订伪装成新的学习。缺乏数据时返回 unknown/insufficient，不填造数据点。

## 3. 时间预算下的计划比较

新增 POST /learning-spaces/{space_id}/plan-comparisons，输入 2—5 个每日分钟预算和 1—30 天窗口，在相同状态/知识/画像快照下进行比较。严格遵守范围、已确认前置依赖、单日容量、用户周预算和截止日期。超预算时选可行子集，返回入选、暂缓、缺失前置或约束阻挡的目标及原因。

使用有界确定性依赖闭包启发式，明确不是全局最优求解器。展示的是目标覆盖、薄弱/到期主题覆盖和估计用时，不是承诺学习收益。比较是预览，不写任务完成状态或掌握度，也不替换当前正式计划；相同幂等 key 返回同一比较快照。

## 4. 策略回放与效果评估

新增 POST /learning-spaces/{space_id}/policy-replays，对本空间已完成的真实历史测验，在每次创建时间上重建可用历史，比较固定顺序、原有规则与自适应规则的主题选择和理由。过去的选择只使用当时可得证据、封存范围和知识版本；纠错在其审计时间之后才生效。

分别报告：状态分数对后续独立答案的预测误差及覆盖样本量；不同策略的选择差异、前置/薄弱主题覆盖等代理指标；真实间隔至少 24 小时、题族不同且独立的延迟复测表现。历史回放无法观测未执行策略的反事实学习结果，因此不给策略分配虚构的学习收益或因果提升；无法比较时明确无数据及排除原因。

## 接口、界面与持久化

后端保持本地令牌、严格 schema、范围检查和幂等约束。复用现有 JSON 快照/证据扩展字段，尽量避免新数据库表。新模块和路由独立文件，主应用与契约快照由集成步骤统一连接。前端在现有风格下增加学习实验入口，展示逐题诊断、演化与复习说明、预算比较及回放报告；demo 模式明确提示需要真实学习数据，不生成伪实验结果。

## 验收

先运行真实行为失败测试再实现，覆盖 memory/SQLite 重启、幂等与并发冲突、辅助/纠错/reset/stale 限制、前置约束、无数据、跨空间隔离、无未来泄漏及预算边界。历史非自适应 API 和数据契约保持兼容，新增字段和操作使用增量快照。最终运行完整后端目录、前端语法和交互契约测试，并做独立代码复核。真实服务/模型测试开关关闭；外部系统验证限制写入验收记录。
