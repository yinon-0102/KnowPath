# 树形 RAG 专项评测结果

本报告对应 tree-v1 的原始正式冻结：`a4902bbde60203eac979df205d52046b971920c5a6b376e308abba4382fdc67f`。数据集包含 40 道真实资料题，四个场景各 10 题，全部位于 dev，heldout 为空。A 是普通混合检索，B1 是在同一 seed 召回上追加树形扩展。

## 服务结果

| 指标 | A | B1 |
| --- | ---: | ---: |
| 计划请求 | 40 | 40 |
| 服务成功 | 39 | 39 |
| 服务失败 | 1 | 1 |
| 服务成功率 | 97.5% | 97.5% |
| P50 延迟 | 39,913 ms | 40,242 ms |
| P95 延迟 | 77,931 ms | 78,341 ms |

两种模式的失败都来自 `tree-v1-14` 的生成响应引用 schema 校验，HTTP 请求本身返回成功。该题没有被事后改写进正式冻结，因此其结果仍按失败计入分母。没有人工质量评审，不能据此宣称答案正确率。

## 检索结果

排名指标只在 39 个服务成功题上计算，必要证据跨度总数为 82。

| 指标 | A 候选 | B1 候选 | A 重排 | B1 重排 |
| --- | ---: | ---: | ---: | ---: |
| Recall@1 | 47.44% | 47.44% | 47.86% | 47.86% |
| Recall@3 | 59.40% | 59.40% | 68.80% | 68.80% |
| Recall@5 | 64.53% | 64.53% | 76.07% | 76.07% |
| Recall@10 | 68.80% | 68.80% | 85.04% | 90.17% |
| Recall@20 | 85.90% | 85.90% | 88.89% | 94.87% |
| Recall@40 | 91.03% | 100.00% | 91.03% | 100.00% |
| MRR | 0.9637 | 0.9637 | 0.9658 | 0.9658 |

B1 的树形扩展加入 371 个节点，其中 8 个直接覆盖既有必要证据，扩展精度为 2.16%，仅由扩展带来的证据 Recall 为 10.26%。这说明树扩展确实找回了一部分相邻证据，但目前引入了大量无关节点；它的收益主要在重排后的 Recall@10 和 Recall@20，而不是首位命中。

上下文证据覆盖率从 A 的 59.40% 提升到 B1 的 61.97%，引用证据覆盖率从 38.03% 提升到 44.44%。候选和重排证据覆盖率分别从 91.03% 提升到 100%。P95 延迟只增加约 0.53%，但没有冻结成本价格表，因此成本指标无法计算。

## 结论和限制

这轮结果支持“树形扩展能补充长尾相邻证据”的检索层判断，但不支持直接宣称树形 RAG 的端到端答案质量更高。原因是有效题目只有 39/40，人工质量未评分，扩展精度也很低。下一轮应先修复 `tree-v1-14` 的引用协议问题，再在不改变金标准的前提下重新跑满 40 题，并补充人工质量评审或可重复的答案点判定。
