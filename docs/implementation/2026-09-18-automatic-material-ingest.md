# 原文件保存与自动入库

延续已批准的接口设计。原始内容存入独立 SQL 二进制表（内存适配器用于测试），与资料版本及幂等记录原子提交，单文件限制 20 MiB。上传不执行正文解析；auto_ingest=true 默认入队，false 仅保存，返回 uploaded 且 run_id=null。显式 ingest 使用保存的原文件，完成解析后以同一 Run 接续现有图谱/向量准备，成功仍需审核发布。

1. 为原文件增加数据库迁移、事务仓储、不可变内容校验及删除联动；保留内部同步解析接口用于已有服务和测试。
2. 接入持久化 material.parse 队列、租约恢复、取消、有限重试与安全错误码；解析不持有数据库事务，提交时校验租约与资料存活。
3. 上传与新版本接口接受 auto_ingest；幂等覆盖该标志，默认真实 queued Run，失败可用新键重新请求。
4. 同步升级 CLI 消费解析及图谱任务、API 文档和测试夹具；运行内存/SQLite/MySQL 与三库回归，执行迁移并检查结构，独立审查后分模块提交推送。

原文件只经上传读取，不开放用户任意磁盘路径。旧版本没有原文件时不伪造内容：已有来源仍可入库，无来源则返回可解释错误。已有发布快照和学习空间绑定不因上传或解析而改变。


## 已实现与验证

- 0013_material_raw 已在本地 MySQL 执行，alembic current 为 head，alembic check 无待补差异；原文件使用 LONGBLOB，SQLite 使用 LargeBinary。
- 上传及新版本接口默认返回真实 queued Run；auto_ingest=false 不调用解析器。原文件解析完成后，以同一 Run 原子创建 graph.prepare；准备成功仍需审核发布。
- 覆盖旧上传键重放、相同内容任务合并、解析格式纠正、20 MiB 限制、PDF 错误码、归档和旧版本保护、取消与删除、租约接管、重试退避、事务失败无残留来源，以及 CLI 分阶段消费。
- 完整学习服务回归：715 passed、32 skipped、1 warning（既有 Starlette/httpx 弃用提示）。执行时显式启用 MySQL、Neo4j 与 Qdrant 集成连接；向量测试使用确定性实现，不调用付费 DashScope 模型。
- 独立代码审查发现的“错误 PDF 扩展名占用文本去重结果”已修复并复审；去重同时匹配内容哈希与实际解析类别，新版本还限定所属资料。

这批完成原文件到候选准备的流程，不代表整个 API 文档已全部验收。资料列表筛选/分页、被空间引用资料的级联删除等仍需后续实现；生产模型质量、语义关系抽取及整体部署验收也不由本批测试证明。
