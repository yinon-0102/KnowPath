# 自动学习笔记验收记录

## 交付范围

实施依据：[已批准计划](../superpowers/plans/2026-10-09-auto-learning-notes.md)。

新增 NotesService、可注入的配置模型生成器、四类 SQL/内存记录、0016 迁移、八项 HTTP 操作。关联测评结算在同一事务登记草稿、独立 Run 和 Outbox；原模型 worker 消费 `note.generate`，模型调用在事务外。发布检查租约、Run、测评结果版本和来源，追加到最新章节，不覆盖个人编辑。

按空间分册，首次计划登记空章节，继承进度节点保留编号和标题。README 自动派生，目录重命名保持不变。不存在本地 Markdown 文件依赖，也不生成历史测评正文。

前端新增顶栏及空间“学习笔记”，支持索引、正文和纠偏编辑、个人段落、历史版本、结构化草稿、失败重试、进度节点与测评结果直达。编辑冲突保留草稿并支持显式合并；离开页面停止轮询。Markdown 禁用原始 HTML 和危险链接，支持代码块，来源沿用原有阅读审计。证据失效的旧正文明确标记为历史学习记录。

## 核心边界

- 重复测评结算复用草稿和任务；自由测评不生成章节；结束会话未测评只显示待总结。
- 真实会话计时使用标准会话投影；缺失为未记录，同一会话多次总结不会重复累计。
- 单次高分不令章节完成；节点任务完成与冻结主题全集当前版本 mastered 均须满足。版本失效、重置、复核、隔离及采用知识更新会同步资格。
- 辅助作答和简答未验证内容不进入已验证核心知识。纠偏按稳定题目身份去重，解释编辑不改变资格，独立复测资格及证据单独展示。
- 模型错误保留草稿且不影响测评结果；重试创建新 Run 并支持 Idempotency-Key；无效或伪造证据引用被拒绝。
- 读取正文、草稿、历史和编辑响应均通过最终事务的辅助作答审计；索引和历史列表仅返回摘要。覆盖共享来源跨空间测评与读取期间新建测评。
- 资料删除清理依赖的正文、纠偏、草稿及历史，并取消相关任务，阻止迟到发布；保留无关生成任务和独立个人段落。空间归档保留，空间删除级联清理并使缓存重放失效。

## 已修复的回归问题

新增接口和表使用独立契约快照，原有 OpenAPI 和 MySQL 契约继续逐项检查。历史 0013 迁移测试仅比较其当时存在的表，不把 0016 当作历史必需结构。

部分消息测试原先受本机 dotenv 的 qdrant 检索设置影响；测试夹具现在显式选择 keyword/legacy，保留对测试目标的真实验证，不修改生产检索配置。worker CLI 的测试桩增加笔记服务，以继续验证日志和资源关闭。

## 使用方式

当前本地 MySQL 已执行迁移，用户手动重启前端、后端及原 model worker 后生效。自动笔记不增加新常驻服务。创建学习计划并完成关联节点测评后，在“学习笔记”查看生成结果；后续关联测评追加同一节点章节。

实际数据库验收时有一个学习空间，没有现存计划节点，因此登记一个空笔记册、零章节、零历史正文、零生成任务；这是业务空状态。

本次未启动常驻服务，未自动提交 Git，也未迁移到远程云数据库。模型成功与失败行为通过注入的确定性模型及错误模型验证，未对付费模型执行额外验收调用。
