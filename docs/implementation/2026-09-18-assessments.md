# 测验、证据与状态持久化实施

沿用已确认的接口和架构设计；本模块采用独立 AssessmentService、共享事务的 SQL/内存仓储，替换 LearningState 内的占位测验实现。

1. 增量迁移保存测验冻结快照、运行 ID、封存 ID、答题修订、证据上下文及状态重置事件。
2. 生成接口固定资料版本及范围；模型出题必须通过题型、来源、答案键、题目数量校验，失败不发布题集。测试显式注入固定题集，生产默认 DashScope。
3. 答题追加保存并校验修订号；批次原子提交；finalize 重试返回同一运行，成绩、逐题证据、状态与运行在同一事务提交。
4. 实现 mastery-v1 的独立证据聚合；未答、无法验证的短答及辅助作答不影响分数，单次答对不直接标记掌握。
5. 保存状态重置和周期，历史证据保留；旧资料版本及重置前测验的成绩不污染当前状态。
6. 严格请求模型、状态/证据筛选，SQLite 和 MySQL 重启、并发、回滚测试；更新运行边界文档并按模块提交。

本批不声称完成计划/会话持久化、完整图谱发布、开放题可靠语义判分、评分复核 worker 或删除级联。短答无可靠判分器时显式 unverified。
