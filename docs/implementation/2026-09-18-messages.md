# 来源约束对话实现

沿用已确认的 API 第 8 节设计。消息请求严格校验 message（1—8000 字）、可选 session_id 和 stream=true，必须带幂等键。未指定 session 时创建独立对话；指定学习会话时验证空间归属和活动状态，不修改计划任务。

事务中封存当前范围、绑定版本及可引用片段并创建 Run/消息。模型调用在事务外，发布时重新检查空间和范围，拒绝过期结果；取消、失败、删除均不得发布正文。会话与消息、幂等结果、引用和 Run 持久化。学习空间删除同时清理对话记录。

首版按选中主题和关键词检索最多 8 个片段，再调用已有 DashScope chat 配置生成 JSON 回答。引用只允许来自封存片段；无效引用和上游异常发布脱敏失败 Run，不回退为伪造回答。检索工具事件只暴露片段引用，内部提示词和密钥不入 SSE。后续向量检索索引可替换检索适配层，不改变接口。

活动测验中直接索要答案或指向当前题目的请求转为保守提示，并记录 assisted；模型不接收隐藏标准答案、rubric 或掌握证据。对话不隐式评分。历史上下文限定同一会话、同一范围版本，防止旧范围内容混入。

测试覆盖三仓储重启/幂等、引用约束、会话隔离、严格请求、模型失败脱敏、取消、范围变化、空间删除、辅助标记和实际 MySQL 事务。


实现说明：消息使用每会话递增序号排序，不依赖 MySQL 时间戳精度。重复幂等请求返回原始 202 响应，实际终态通过 Run 查询；发生唯一键竞争或事务重试时，只调度最终提交的消息。服务重启沿用已有 RUN_INTERRUPTED 规则，不自动重试模型调用。学习会话在生成期间结束时，结果以 SESSION_FINISHED 失败收束。

SSE 当前在模型返回且引用校验通过后分块发布正文，不是上游 token 级流式透传。来源 ID 校验保证引用属于封存资料，不代表已经证明回答语义正确。活动测验提示识别覆盖题目 ID、完整题干和明确答案/提示意图；自然语言改写仍有识别局限，需要后续评测。此模块未实现向量召回，也不改变现有图谱占位实现。

数据库迁移 0009_messages 建立 learning_conversations 与 learning_messages（含会话序号唯一约束）。迁移已在 SQLite 验证升降级与元数据一致性，并已在项目 MySQL 应用。

最终验证：包含实际 MySQL 的 learning 全套回归 399 passed、24 skipped；跳过项来自仓储类型限定及未配置的独立测试条件。保留已有 Starlette/httpx 弃用警告。alembic check 无待生成迁移。模型边界使用模拟 HTTP 验证，未调用付费模型 API；独立审查提出的索答复数漏判已修复，并覆盖普通编程提问误判回归。
