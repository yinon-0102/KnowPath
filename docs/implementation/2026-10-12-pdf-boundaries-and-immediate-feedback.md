# PDF 学习边界与逐题反馈验收（2026-10-12）

## 结论与根因

使用用户指定的《未成年人保护法（2024修正·37页·纯文字）》实际文件完成浏览器验收。
旧学习图谱使用按页解析的 37 个片段，没有章节路径；标题来自片段开头，标题截断进一步掩盖学习范围。
RAG 的语义切分不控制学习图谱，因此仅优化检索切块或加长标题不足以解决节点混杂。

现在按完整法条组合学习主题，不跨章/节；每组最多六条或目标 1600 字，超长单条保持完整。
跨页条文属于同一个学习主题，来源仍按原 PDF 页码、行号保留。
支持“第一章总则”等无空格标题。

实际文件复核：37 页、132 条、27 个学习主题、60 个来源片段。
全部 763 行非空原文各覆盖一次，逐片段原文与页码/行号对应一致，132 条法条顺序完整保留。
27 个主题包含文档说明，不能简单等同于 27 个法条组。

## 用户链路与修复

| 环节 | 已核查行为 / 修复 |
| --- | --- |
| 上传与发布 | 实际选择本地 PDF、后台解析、审核发布；资料列表提供直接审核入口 |
| 创建空间 | 修正已发布资料缓存；已有但未发布的资料显示准确提示 |
| 学习范围与计划 | 展示 27 个主题，选取第一章的三个法条组生成学习计划 |
| 节点阅读 | 显示完整章节、法条范围和来源页码；节点标题提供完整文字提示 |
| 学习会话 | 开始学习、真实模型讲义、原文问答、结束后进入关联测评 |
| 逐题反馈 | 提交即显示本题结果、用户答案、正确/参考答案、解析及来源页码；点击下一题才继续 |
| 刷新恢复 | 第一题解析期间刷新，可恢复已提交答案和解析，避免重复提交 |
| 评分完整性 | 已看过解析的题目禁止修改；同源后续题、其他空间及生成中的测评记录辅助曝光 |
| 修改旧答案 | 曝光前的已提交答案保留独立性，曝光后修改该答案的新版本标记辅助 |
| 汇总与笔记 | 完成五题并汇总，真实模型生成笔记正文和纠偏；保留全部题目的可读作答记录 |
| 显示细节 | 解析中的内部选项 ID 转成选项文字；27 秒不显示成 0 分钟；计划时长最多一位小数 |
| 响应式布局 | 1440px / 390px 反馈页面均未出现横向溢出 |

笔记失败复现为 `MODEL_INVALID_RESPONSE`。原输入同时携带全部历史题目结果和部分可用证据，容易诱导模型使用不允许的证据 ID。
修正为明确证据 ID 白名单，并只将对应题目/结果送入模型；原始完整快照仍用于用户学习记录。
证据校验继续拒绝虚构 ID。真实模型后续生成成功。

简答题没有可靠判分时明确显示待核验及参考解析，不伪造“正确”。
即时反馈通过 `include_feedback` 请求字段启用，旧批量调用默认行为保留。

浏览器测试使用临时内存应用、真实 PDF 解析、实际 API/前端和项目配置的真实模型。
图谱/向量准备使用测试适配器，检索使用关键词后端；本次未验收生产 MySQL、Neo4j、Qdrant 或其迁移。

本次结构切分针对带章/节、法条标记的可提取文字 PDF。其他布局沿用原有解析回退；
扫描件、多栏、复杂表格和图片混排的通用版面恢复未在本次解决。

旧资料不会静默改写：重新上传为新版本时，旧的按页法律 PDF 会触发结构升级，避免直接复用旧解析。
随后审核发布新版本，并在已有学习空间显式采用资料更新、重新生成计划；旧测评/会话仍保留冻结来源。
运行中的正式后端、前端与 Worker 需要重新启动以加载本次代码。
测试专用进程在验收结束后关闭，未向用户正式数据写入测试学习记录。
