# 学习空间删除

DELETE /learning-spaces/{space_id} 校验严格的 confirm=true 与 expected_version。当前同步完成事务并返回 202、真实 succeeded Run。

删除该空间的测评、答案、证据、掌握状态、重置记录、计划、任务、会话事件、导出、纠正记录及关联 Run/events/outbox。共享资料与其他空间保留。内存仓储和 SQL 使用同一事务，Run 创建失败时整批回滚。清理本进程缓存只发生在事务提交后。

相关幂等记录保留请求指纹和资源 ID，清空旧响应，以 RESOURCE_DELETED（HTTP 410）拒绝重放，避免泄漏已删除内容或重新创建空间。不同请求复用同一 key 仍然冲突。

删除先锁测评再锁空间，与评分保持相同锁顺序；MySQL 死锁沿用命令重试。生成任务在调用模型前、提交结果时检查测评是否已删除，迟到输出丢弃。

验证覆盖：内存/SQLite/MySQL 三仓储重启读取、共享资料保留、原子回滚、严格确认、过期版本、幂等删除标记、与评分并发及迟到题目生成。

限制：消息、知识纠正和图谱发布仍有尚未补齐的接口实现，不能据此宣称所有接口已完成。

消息和纠错 Run 使用 result_ref.space_id 持久化空间归属，创建/发布与空间存在检查共享事务锁；空间删除同时清理其 SSE 内容。升级前若产生了未记录空间归属的旧消息 Run，现有数据无法可靠反推其所属空间，因此不能自动清理这些历史孤立记录。
