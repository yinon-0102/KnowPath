# 四项后端正确性修复

日期：2026-09-26。范围为任务周期、测评辅助判定、存储配置和题目纠错；未增加算法展示或其他产品功能。

## 任务周期

规划策略升级为 planner-v2。完成或跳过只关闭当前任务周期，新证据、到期复习及知识更新可以产生后续任务；原记录保留为历史。周期签名不受 include_review 展示偏好或与当前任务无关的时钟标志影响，兼容 planner-v1 已完成记录。

延期到期会使计划显示 needs_replan，显式 local_replan 后恢复 pending；未到期不能启动会话。知识更新产生的替代诊断任务也继承尚未到期的延期时间与备注。这里没有新增后台自动调度器。

## 测评辅助判定

普通解释、同源跨空间回答，以及交给模型的历史/召回上下文，均按原始资料来源与活动测验的交集审计。自然语言提示识别只决定回答方式，不再决定证据是否独立。回答发布和辅助标记在同一事务内提交，未交付的失败/取消结果不污染证据；已经结束的测验不被之后的聊天追溯改写。

来源匹配覆盖当前 ready/in_progress 测验及仍在 generating 的题集，RAG 引用映射回原始资料块。人工题目复核详情展示原文时，也执行同样的来源辅助审计。

历史消息 SSE 重放按实际返回的文本重新审计，跳过文本的游标和仅查询 Run 元数据不标记辅助。旧消息缺少来源记录时追溯原始历史/召回消息，无法安全追溯则拒绝交付。直接原文读取也复用相同的锁定、重查和重试路径，防止并发新建测验被漏记。

## 存储配置

提供的 Compose 中 MySQL、Neo4j、Qdrant、MinIO 端口均限制到 127.0.0.1；配置不再提供固定弱口令，Qdrant API key 传递到业务客户端。数据库/Alembic 必须显式配置连接，测试用 SQLite 仍可显式启用。

本次仅修改代码、配置模板与操作说明，未读取或修改实际 .env、数据库口令、运行中容器或数据卷。既有部署不会自动套用这些设置；已有数据的口令迁移、客户端配置同步和容器重建应按 infra/README.md 执行，不能通过清空数据卷替代迁移。

## 题目纠错

新增三个接口，完整字段见 docs/API.md：

- POST /api/v1/assessments/{assessment_id}/question-reviews：举报已完成测验的封存题目，立即隔离其评分及掌握度证据。
- GET /api/v1/assessments/{assessment_id}/question-reviews：返回版本、审计记录、原始/当前题目及封存来源。
- POST /api/v1/assessments/{assessment_id}/question-reviews/{review_id}/resolve：携带版本、来源依据与明确确认，人工更正、作废或驳回。

原始题目和作答保持封存，纠错追加事件、替代证据并原子重算结果。复核保留原观察时间、题目 family、submission 及 assisted/reset/旧知识版本限制，不把复核当作新的间隔学习。后续评分复核使用已确认的答案。

裁决是本地单用户的人工确认，只影响指定测验中的题目快照，不是模型自动真值校验，也不批量修改其他同类题。开放题仍为 unverified。接口已实现，本次未增加前端纠错页面。
