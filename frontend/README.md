# KnowPath 前端

基于苹果官网的简洁导航、留白与大幅展示思路，为 KnowPath 重新设计的学习界面。使用雾白、浅灰、低饱和蓝、淡绿和浅紫；所有插画、图标和字体均无需外部网络资源。

## 立即运行新版

需要 **Node.js 20 或更新版本**。项目没有第三方运行时依赖，**不需要 npm install**。

在 VS Code 打开项目，在终端执行：

```powershell
cd frontend
npm.cmd run dev
```

如果终端已经在 `frontend`，只执行第二行。Windows 使用 `npm.cmd` 可避免 PowerShell 的 `npm.ps1` 执行策略限制；macOS / Linux 可直接使用 `npm run dev`。

浏览器打开 **http://127.0.0.1:5173/**。默认进入明确标注的示例体验，可直接操作所有主要页面。按 `Ctrl+C` 停止前端服务。

> 根目录已有的 `index.html` 和 `start-local.ps1` 保持原样，仍启动旧版页面。**新版请使用本目录的 `npm.cmd run dev`**。如果旧版已占用 5173，先停止旧前端，或执行 `npm.cmd run dev -- --port 5174`。更换端口后，真实后端的 `LEARNING_ALLOWED_ORIGINS` 也需添加相应来源。

### 示例模式

- 内置三个示例空间和四份明确标注的示例资料。
- 创建空间、文本导入、主题范围和任务状态保存在当前浏览器 `localStorage` 中。
- 示例图谱中新增主题按 Markdown 标题提取，并非 AI 提取；示例问答是本地资料摘录，并非模型生成。
- PDF 原文件保存在当前浏览器的 IndexedDB，可用浏览器 PDF 阅读器打开；解析知识仍需要连接后端导入。示例文本单文件最多保存 100 万字符，总计最多约 180 万字符，避免耗尽浏览器存储。
- 可在右上角设置里选择“恢复初始示例”，确认后清除新增示例数据；不会影响真实后端数据。
- 专注时长和任务完成不直接写成知识掌握度。

### 连接真实后端

1. 按 [`../py/README.md`](../py/README.md) 准备数据库、迁移、模型配置及 Python 依赖。
2. 在 `py` 目录的独立终端中启动以下进程：

```powershell
uv run python -m uvicorn knowpath_backend.learning.main:app --host 127.0.0.1 --port 8000
uv run python -m knowpath_backend.learning.graph_worker_cli
uv run python -m knowpath_backend.learning.model_worker_cli
```

这三条是**三个持续运行的进程，分别使用一个终端**；前端则继续在第四个终端运行。也可使用项目现有运行配置启动后端。

3. 前端右上角打开设置，输入与后端一致的本地会话令牌，点击“连接本地服务”。
4. 导入资料 → 等待解析 → 打开资料详情 → “审核知识图谱” → 审阅变更并发布。
5. 用已发布的资料创建空间 → 选择学习主题 → 生成计划或开始问答。

默认令牌文件为 `py/.learning-token.local`，也可能通过 `LEARNING_LOCAL_TOKEN` 或 `LEARNING_LOCAL_TOKEN_FILE` 配置；以实际后端设置为准。前端只将令牌保存在当前标签页的 `sessionStorage`，通过 `X-Local-Token` 请求头发送，代码里不包含密钥。也支持通过 `#local_token=…` 接收已有启动器的令牌片段，读取后会立即从地址栏移除。

真实模式完全使用后端数据，连接失败时显示具体错误，不会混入示例数据。POST 请求提供幂等键，任务更新携带版本号，列表会处理后端分页。知识图谱检查空间绑定快照的版本，问答断线恢复使用同一个任务及 `Last-Event-ID`。

### 当前范围

- 知识来源请求携带所属学习空间，并保留后端的测评期间原文查阅记录。新版引用通过引用解析接口定位，不将检索分块 ID 当作原文片段 ID。
- 点击来源会在新标签页打开已关联的 PDF，保留图谱位置；后端返回可靠页码时跳到对应页。新上传 PDF 自动按资料版本保留本地副本。
- 当前后端没有原文件下载接口。历史资料需在“查看原文 / 管理 PDF”中补选一次原文件；PDF 资料按版本内容哈希校验。文字资料可关联阅读用 PDF，但不假定页码相同。关联文件只在当前浏览器保存，不上传、不修改后端知识。清理网站数据或换浏览器需重新选择；存储不可用时仅保留本次会话并提示。

- 图谱审核逐项展示冲突，可选保留原内容、采用新版或保留两种内容并填写理由。知识纠错采用单独的候选与确认流程；资料发布和空间采用新知识是两个明确步骤。
- 资料管理、测评详细结果与复核、知识更新，以及状态、证据、任务会话、导出均在现有模块下提供独立子页面。入口和验证说明见 [`../docs/reviews/2026-10-05-frontend-integration.md`](../docs/reviews/2026-10-05-frontend-integration.md)。
- 资料归档暂不支持恢复；这是当前后端合同的限制。资料删除会先展示关联空间，要求明确确认；不要使用真实资料做删除测试。
- 测评可设置难度比例预设、记录当前页面作答耗时、取消生成。结果页逐题展示反馈及来源，题目裁决必须勾选已核对的封存来源。
- 任务的“学习”入口记录真实会话；原有专注倒计时仍是本地工具。会话的起止间隔包含暂停，不声称是有效专注时长。
- 管理命令保留幂等键和已知后台任务；超时可查询原任务，失败保留表单内容。当前标签页的待处理操作、会话和纠错候选保存在 sessionStorage，清除标签页存储后无法从前端恢复这些本地入口。
- 当前标签页生成的计划 ID 保存在 `sessionStorage` 中，可在刷新后继续加载。尚无跨标签页的历史计划列表页面。
- 聊天界面保留当前页面会话记录；真实对话由后端持久化，但本版未提供历史会话列表。
- 后端与模型未启动时，可完整查看示例界面；真实 AI 功能需要相应服务和有效配置。

## 代码结构

```text
frontend/
├── index.html                 # 页面入口、元信息、无障碍跳转
├── package.json               # 零第三方依赖的运行／检查命令
├── server.mjs                 # 回环地址 HTTP 服务，公开文件白名单
├── assets/
│   ├── favicon.svg            # KnowPath 标志
│   └── knowledge-orbit.svg    # 本地知识连接插画
├── src/
│   ├── app.js                 # 路由、页面、交互与状态协调
│   ├── styles.css             # 色彩、组件、响应式、减少动画偏好
│   ├── api.js                 # 真实后端契约、认证、SSE 与错误处理
│   ├── store.js               # 示例数据、存储、文本转义和文件校验
│   └── icons.js               # 内联 SVG 图标
└── tests/                     # Node 内置测试，无需安装测试框架
```

页面路由使用 `#/overview`、`#/spaces`、`#/space/:id`、`#/materials`、`#/graph`、`#/plan`、`#/assistant`，因此刷新子页面不需要服务器回退规则。

`src/styles.css` 顶部的 CSS 变量集中定义主要配色。API 基地址在 `src/api.js` 中；修改后还需同步开发服务器的 CSP `connect-src` 和后端 CORS 配置。

## 检查

```powershell
npm.cmd run check
npm.cmd test
```

测试覆盖输入转义、上传限制、示例引用一致性、损坏存储恢复、API 认证与幂等键、分页、版本化任务更新、SSE Unicode 分片、断线恢复、停止读取及静态服务公开范围。API 测试使用模拟响应，不会修改真实后端数据。

本地服务器只公开白名单中的页面与资源，不提供目录列表、后端源码、令牌或环境文件。部署静态文件时也应只发布 `index.html`、`src/` 和 `assets/`，不要把项目根目录作为公网静态目录。

## 旧版根目录页面说明（原有内容保留）

以下说明仅适用于原先的根目录 `index.html`，不是上面的新版前端启动方式。

入口为项目根目录 `index.html`，后端为 `py/` 中的真实 `/api/v1` 服务。

在项目根目录启动（需要已安装 `py/.venv` 依赖并准备好 `py/.env`）：

```powershell
.\start-local.ps1 -OpenBrowser
```

需要同时启动仓库的 MySQL、Neo4j、Qdrant 容器时，使用
`.\start-local.ps1 -StartStorage -OpenBrowser`。脚本不自动执行数据库迁移；首次 SQL
部署请先按 [后端说明](../py/README.md) 应用 Alembic 迁移。现有服务通过进程与 HTTP
检查后复用，端口被其他进程占用时会报错，不会关闭或替换它们。

前端地址为 `http://127.0.0.1:5173/`，API 为 `http://127.0.0.1:8000`。
服务绑定回环地址，日志在被 Git 忽略的 `.runtime.local/`。
前端 HTTP 服务只提供 `/` 和 `/index.html`，不会公开 `.env`、本地令牌或源码目录。
不要在仓库根目录启动会公开全部文件的通用静态服务器。

`-OpenBrowser` 从与后端一致的环境变量、`py/.env` 或本地令牌文件读取令牌，
通过浏览器 URL 片段交给页面；片段不会发送给服务器。页面将令牌保存在当前标签页的
`sessionStorage`，随后移除 URL 片段；API 请求用 `X-Local-Token` 请求头认证。
默认令牌文件为 `py/.learning-token.local`；`LEARNING_LOCAL_TOKEN_FILE` 可覆盖路径。
勿分享带令牌的链接或提交本地配置。已有浏览器标签页未带令牌时，可重跑上面的命令。

当前连接的是真实的学习空间、资料与图谱 API，不存在最初假设的 `/api/learners`
和 `/api/reason` 接口；学习空间不等同于学习者。服务暂未提供该假设接口中的推荐路径
与三项评分，页面不会伪造这些数据。尚未配置模型密钥时，本地健康检查和资源 API
可以连通，需要模型的任务仍需配置后再运行。
