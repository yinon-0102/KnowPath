# KnowPath 前端

基于苹果官网的简洁导航、留白与大幅展示思路，为 KnowPath 重新设计的学习界面。使用雾白、浅灰、低饱和蓝、淡绿和浅紫；所有插画、图标和字体均无需外部网络资源。

## 启动前端

需要 **Node.js 20 或更新版本**。项目没有第三方运行时依赖，**不需要 npm install**。

在 VS Code 打开项目，在终端执行：

```powershell
cd frontend
npm.cmd run dev
```

如果终端已经在 `frontend`，只执行第二行。Windows 使用 `npm.cmd` 可避免 PowerShell 的 `npm.ps1` 执行策略限制；macOS / Linux 可直接使用 `npm run dev`。

浏览器打开 **http://127.0.0.1:5173/**。页面自动读取本地鉴权配置并加载后端数据，无需输入令牌。按 `Ctrl+C` 停止前端服务。后端未启动或鉴权配置不可用时，页面显示服务错误及重试入口；新安装没有资料和空间时显示空状态。

前端入口统一为 `frontend/index.html`。在项目根目录执行 `.\start-local.ps1 -OpenBrowser` 可以启动 API 和同一 Node 前端；加 `-StartStorage` 同时启动容器。脚本不自动执行数据库迁移，也不启动图谱和模型后台进程；这些需要按下文单独准备。脚本只复用能确认属于本项目的进程，端口占用时会报错。更换前端端口可执行 `npm.cmd run dev -- --port 5174`，并将相应来源加入后端 `LEARNING_ALLOWED_ORIGINS`。

## 页面与功能

顶栏保留 **学习首页 / 学习空间 / 资料库** 三项。进入空间后，在五个主分区中完成学习：

| 分区 | 可用操作 |
| --- | --- |
| 学习首页 | 空间与资料统计、最近空间、依据真实会话与任务状态给出下一步入口 |
| 空间首页 | 当前目标、空间累计节点进度、继续活动会话、待复习和知识更新提示 |
| 学习计划 | 生成与重新安排计划、当前计划节点进度、任务完成/跳过/延期/备注、会话开始/暂停/恢复/结束；次级入口提供预算比较 |
| 资料与范围 | 绑定资料、选择与排除主题、浏览知识结构、核对来源、查看和采用知识更新 |
| 学习助手 | 按空间和任务上下文提问、资料范围筛选、来源引用、SSE 接收/恢复/停止 |
| 测评与复习 | 测评练习与掌握复习两个子页；逐题结果、评分复核、题目反馈与裁决、证据和复习安排 |
| 资料库 | 上传、版本管理、解析与审核发布、重命名、归档、删除和阅读 |
| 空间设置与高级分析 | 空间名称、目标、时间与偏好、导出、重置与归档；高级分析提供历史策略回放 |

全局还提供 `Ctrl/⌘ + K` 搜索、移动端菜单、弹窗焦点管理、错误与空状态、减少动画偏好。

### 学习顺序与节点记录

1. 在资料库导入资料，等待解析，审阅候选并发布知识版本。
2. 用已发布资料创建空间，在“资料与范围”保存本次学习主题与排除项；在空间设置填写目标、时间预算及偏好。
3. 在“学习计划”生成任务。需要诊断时可先做测评；诊断不是进入学习的必经步骤。
4. 点击待完成节点查看知识点与来源，进入任务学习；会话可暂停、恢复，或带本次会话上下文向学习助手提问。
5. 结束会话并保存后，核对任务并手动确认完成。结束会话本身不会把任务标成完成，也不会直接写成知识掌握度。
6. 从任务发起关联练习或复测，在节点详情查看本次作答结果；在“测评与复习”查看证据与下次复习时间。
7. 根据测评、到期复习及资料更新重新规划，再继续下一个节点。历史轮次保留在空间累计进度中。

完成节点沿用低饱和蓝底和勾选；待完成节点为灰白空心，正在学习显示蓝色描边，跳过或延期仍保持灰色并带状态标记。相邻节点均已完成时连接线着色。节点支持键盘打开；详情抽屉可以滚动，按 Esc 关闭并回到触发节点。

点击节点可查看真实会话起止时间、累计起止间隔、任务备注、关联测评及知识点来源。起止间隔包含暂停；旧记录没有足够时间数据时显示“未记录”。测评只显示明确关联该任务或会话的记录。来源优先使用封存快照，补用当前资料时会标明。历史任务提供查看入口，执行学习及测评须使用当前计划。

### 准备后端与自动连接

1. 按 [`../py/README.md`](../py/README.md) 准备数据库、迁移、模型配置及 Python 依赖。
2. 在 `py` 目录的独立终端中启动以下进程：

```powershell
uv run python -m uvicorn knowpath_backend.learning.main:app --host 127.0.0.1 --port 8000
uv run python -m knowpath_backend.learning.graph_worker_cli
uv run python -m knowpath_backend.learning.model_worker_cli
```

这三条是**三个持续运行的进程，分别使用一个终端**；前端则继续在第四个终端运行。也可使用项目现有运行配置启动后端。

3. 启动 Node 前端，打开页面，等待自动连接。
4. 导入资料 → 等待解析 → 打开资料详情 → “审核知识图谱” → 审阅变更并发布。
5. 用已发布的资料创建空间 → 选择学习主题 → 生成计划或开始问答。

默认令牌文件为 `py/.learning-token.local`，也可在 `py/.env` 中设置 `LEARNING_LOCAL_TOKEN` 或 `LEARNING_LOCAL_TOKEN_FILE`；Node 前端使用与后端一致的配置。回环地址接口 `GET /__knowpath/local-auth` 读取当前配置并返回令牌，响应禁止缓存。令牌仅保存在当前标签页的 `sessionStorage`，业务请求通过 `X-Local-Token` 请求头发送，浏览器地址和静态文件不包含令牌。后端进程环境变量如覆盖鉴权设置，启动 Node 前端时应继承同样的配置。

自定义令牌文件的相对路径以 `py` 为基准；API 也应从 `py` 启动。若从其他目录启动 API，请使用绝对路径，确保两个服务读取同一文件。后端重启或凭据变化后，可在服务状态页点击“重新自动连接”。

所有业务页面和操作均使用后端数据，连接失败时显示具体错误。POST 请求提供幂等键，任务更新携带版本号，列表会处理后端分页。知识图谱检查空间绑定快照的版本，问答断线恢复使用同一个任务及 `Last-Event-ID`。

### 当前范围

- 知识来源请求携带所属学习空间，并保留后端的测评期间原文查阅记录。引用通过引用解析接口定位，不将检索分块 ID 当作原文片段 ID。
- 点击来源会在新标签页打开已关联的 PDF，保留图谱位置；后端返回可靠页码时跳到对应页。新上传 PDF 自动按资料版本保留本地副本。
- 当前后端没有原文件下载接口。历史资料需在“查看原文 / 管理 PDF”中补选一次原文件；PDF 资料按版本内容哈希校验。文字资料可关联阅读用 PDF，但不假定页码相同。关联文件只在当前浏览器保存，不上传、不修改后端知识。清理网站数据或换浏览器需重新选择；存储不可用时仅保留本次会话并提示。

- 图谱审核逐项展示冲突，可选保留原内容、采用新版或保留两种内容并填写理由。知识纠错采用单独的候选与确认流程；资料发布和空间采用新知识是两个明确步骤。
- 资料管理、测评详细结果与复核、知识更新，以及状态、证据、任务会话、导出均在现有模块下提供独立子页面。入口和验证说明见 [`../docs/reviews/2026-10-05-frontend-integration.md`](../docs/reviews/2026-10-05-frontend-integration.md)。
- 资料归档暂不支持恢复；这是当前后端合同的限制。资料删除会先展示关联空间，要求明确确认；不要使用真实资料做删除测试。
- 测评可设置难度比例预设、记录当前页面作答耗时、取消生成。结果页逐题展示反馈及来源，题目裁决必须勾选已核对的封存来源。
- 任务的“学习”入口记录真实会话；原有专注倒计时仍是本地工具。会话的起止间隔包含暂停，不声称是有效专注时长。
- 管理命令保留幂等键和已知后台任务；超时可查询原任务，失败保留表单内容。待处理操作和纠错候选的本地入口保存在 sessionStorage；清除后这些本地入口可能丢失。当前计划和活动学习会话由工作台接口恢复，包括暂停状态。
- 当前计划由后端恢复，空间累计进度按历史轮次分页展开。同周期继承任务保持节点身份；进入新的学习或复习周期时生成新节点。
- 聊天界面保留当前页面会话记录；真实对话由后端持久化，但本版未提供历史会话列表。
- 资料解析需要图谱后台进程，出题与回答需要模型后台进程及有效模型配置。后台进程未启动时，任务可能保持等待状态；可在服务状态页检查配置和待处理任务。

## 代码结构

```text
frontend/
├── index.html                 # 页面入口、元信息、无障碍跳转
├── package.json               # 零第三方依赖的运行／检查命令
├── server.mjs                 # 回环地址 HTTP 服务，公开文件白名单
├── assets/
│   ├── favicon.svg            # KnowPath 标志
│   └── knowledge-orbit.svg    # 本地知识连接插画
├── src/
│   ├── app.js                 # 路由、页面、交互与状态协调
│   ├── styles.css             # 色彩、组件、响应式、减少动画偏好
│   ├── api.js                 # 真实后端契约、认证、SSE 与错误处理
│   ├── store.js               # 页面偏好存储、文本转义和文件校验
│   ├── learning.js            # 测评、复习、预算比较及策略回放
│   ├── workspace.js           # 独立管理页请求与恢复
│   ├── workspace-view.js      # 独立管理页表单和结果
│   ├── workbench.js           # 空间路由、工作台恢复与节点周期
│   ├── progress.js            # 节点进度与学习记录展示
│   ├── notes.js               # 学习笔记、正文编辑与版本历史
│   └── icons.js               # 内联 SVG 图标
└── tests/                     # Node 内置测试，无需安装测试框架
```

页面路由使用 `#/overview`、`#/spaces`、`#/materials`、`#/notes` 和 `#/space/:id/:section`。空间 section 包括 `overview`、`plan`、`materials`、`assistant`、`assessment`、`review`、`settings`、`analysis`、`notes`；预算比较为 `plan?view=budget`。资料结构页使用 `#/materials/graph/:id`，独立管理页继续使用 `#/manage/...`。旧 `#/plan`、`#/assistant`、`#/learning/...` 入口会转到当前空间对应分区，旧 `#/graph` 转到资料库。所有路由使用 hash，刷新无需服务器回退规则。

学习笔记保存在后端数据库中。关联计划节点的测评完成后，模型后台进程自动整理笔记；自由测评不会创建节点笔记。正文支持编辑、个人段落和历史版本，版本冲突会保留未提交修改。部署前在 `py/` 执行 `uv run alembic upgrade head`，应用 `0016_learning_notes` 新增的四张表，再启动模型后台进程。键盘提问使用 Enter 发送、Shift+Enter 换行。

`src/styles.css` 顶部的 CSS 变量集中定义主要配色。API 基地址在 `src/api.js` 中；修改后还需同步开发服务器的 CSP `connect-src` 和后端 CORS 配置。

## 检查

```powershell
npm.cmd run check
npm.cmd test
```

测试覆盖输入转义、上传限制、API 认证与幂等键、分页、版本化任务更新、SSE Unicode 分片、断线恢复、停止读取、静态服务公开范围和自动鉴权；包括工作台恢复与迟到响应隔离、节点周期/状态/历史、学习详情及测评关联、笔记编辑与冲突恢复、回车发送和全部页面模块的 HTTP 加载。API 测试使用隔离响应，不会修改真实后端数据。

本地服务器只公开白名单中的页面与资源及回环鉴权接口，不提供目录列表、后端源码或环境文件。鉴权接口拒绝外部 Host，令牌文件不作为静态文件公开。请使用 Node 前端服务；直接双击 HTML 或只部署静态文件无法自动读取本地鉴权配置。日志位于 `.runtime.local/`，不要把项目根目录作为公网静态目录。
